# js-primer-practice

[JavaScript Primer](https://jsprimer.net/) を読みながら、章ごとに小さなものを作って練習するリポジトリ。

## 進捗チェックリスト

- [x] ① 基本文法（変数・データ型・演算子・条件分岐・ループ）→ [`01-basic`](./01-basic)
  - 作ったもの：自己紹介、typeofで型確認、演算子、おみくじ、ループ、じゃんけん、数当てゲーム
- [ ] ② 関数・スコープ・オブジェクト・配列・文字列
  - 作るもの：文字数カウンター、買い物リストの合計金額、単語の頻度集計
- [ ] ③ 分割代入・クラス・例外処理・Map/Set
  - 作るもの：家計簿ロジック
- [ ] ④ 非同期処理（Promise / async await）・JSON・fetch
  - 作るもの：公開APIからデータを取ってきて表示するページ
- [ ] ⑤ ユースケース章（Todoアプリなど）
  - 作るもの：Todoアプリ（本の通りに作ったあと、自分で機能追加）

## 進め方

1. 該当する章を読む（写経して動かす）
2. 自分で少し変えてみる
3. お題を作る
4. 1つ作ったら1コミット（例：`数当てゲームを追加`）
5. 詰まったところ・気づきを、学習ログに残す

## 実行方法

```bash
node 01-basic/intro.js
```

## 学習ログ

| 章 | 作ったもの | 一言メモ |
| --- | --- | --- |
| 変数と宣言 | 自己紹介（`intro.js`） | `const` は再代入できない、`let` はできる |
| データ型とリテラル | 型の確認（`types.js`） | `typeof null` は `"object"` になる |
| 演算子 | 税込み計算など（`operators.js`） | 比較は `===` を使う。`==` は型変換が起きる |
| 条件分岐 | おみくじ（`omikuji.js`） | `if` は文なので、変数に入れられない |
| ループと反復処理 | カウントダウン、合計（`loop.js`） | 合計の変数は `0` から始める |
| 総合 | じゃんけん、数当てゲーム | `%` は、マイナスだとマイナスの結果になる。`break` でループを止める |
